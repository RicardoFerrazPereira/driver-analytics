# Driver Analytics

Plataforma de análise de dados para motoristas de aplicativo.

## Objetivo

Automatizar a coleta, armazenamento e análise de corridas da Uber e 99.

## Tecnologias

- Python
- PostgreSQL
- Docker
- SQLAlchemy
- Pandas
- Playwright (futuro)
- FastAPI (futuro)
- Metabase (futuro)
